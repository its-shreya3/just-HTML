# 🏗️ HTML STRUCTURE

Every HTML page starts with a basic document structure:

```html
<!DOCTYPE html>

<html lang="en">

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>

</body>

</html>
```

### 🔍 Basic Structure

```text
<!DOCTYPE html>  → 📌 Defines HTML5
<html>           → 🌐 Root element
<head>           → ⚙️ Page information
<title>          → 🏷️ Page title
<body>           → 👀 Visible content
```

---

# 🏷️ HTML TAGS

Tags are the building blocks of HTML.

```html
<h1>Hello World</h1>

<p>This is a paragraph.</p>

<strong>Important Text</strong>

<em>Emphasized Text</em>
```

### 🔥 Common Tags

| Tag        | Purpose             |
| ---------- | ------------------- |
| `<h1>`     | 🔠 Main heading     |
| `<p>`      | 📝 Paragraph        |
| `<br>`     | ↩️ Line break       |
| `<hr>`     | ➖ Horizontal line   |
| `<strong>` | 💪 Important text   |
| `<em>`     | ✨ Emphasized text   |
| `<div>`    | 📦 Block container  |
| `<span>`   | 🔹 Inline container |

---

# 🔠 HEADING TAGS

HTML provides six levels of headings:

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
```

```text
<h1> ⭐⭐⭐⭐⭐⭐
<h2> ⭐⭐⭐⭐⭐
<h3> ⭐⭐⭐⭐
<h4> ⭐⭐⭐
<h5> ⭐⭐
<h6> ⭐
```

# ⚠️ DEPRECATED TAGS

Some older HTML tags are no longer recommended in modern HTML.

Examples:

```html
<font>
<center>
<marquee>
<big>
<strike>
```

> ⚠️ These tags are included in this repository for **learning and historical understanding**. Modern websites should generally use CSS instead.

# 🧩 HTML ELEMENTS

An HTML element generally contains:

```text
Opening Tag
     ↓
   Content
     ↓
Closing Tag
```

Example:

```html
<p>Hello World</p>
```

```text
<p>          → Opening Tag
Hello World  → Content
</p>         → Closing Tag
```

---

# ↔️ INLINE vs BLOCK ELEMENTS

### 📦 Block Elements

```html
<div>
<p>
<h1>
<section>
<header>
<footer>
<table>
<form>
```

➡️ Usually begin on a new line.

### 🔹 Inline Elements

```html
<span>
<a>
<strong>
<em>
<img>
```

➡️ Usually occupy only the space they need.

---

# ⚙️ HTML ATTRIBUTES

Attributes provide additional information about elements.

```html
<img
    src="profile.jpg"
    alt="Profile Image"
    width="200">
```

### 🔑 Examples

```text
src     → 🖼️ Image source
href    → 🔗 Link destination
alt     → ♿ Alternative text
width   → 📏 Width
height  → 📐 Height
id      → 🆔 Unique identifier
class   → 🎨 CSS class
title   → 💬 Tooltip
```

# 📊 HTML TABLES

Tables are used to display structured information.

```html
<table border="1">

    <tr>
        <th>Name</th>
        <th>Technology</th>
    </tr>

    <tr>
        <td>Shreya</td>
        <td>HTML</td>
    </tr>

</table>
```

### 🧱 Table Structure

```text
<table>
   │
   ├── <tr> → Row
   │     │
   │     ├── <th> → Header
   │     └── <td> → Data
   │
   └── ...
</table>
```

# 📝 HTML FORMS

Forms allow users to enter information.

```html
<form>

    <label>Name:</label>
    <input type="text">

    <br><br>

    <label>Email:</label>
    <input type="email">

    <br><br>

    <label>Password:</label>
    <input type="password">

    <br><br>

    <button type="submit">
        Submit 🚀
    </button>

</form>
```

### 🎛️ Common Form Controls

```text
📝 text
📧 email
🔒 password
🔘 radio
☑️ checkbox
📅 date
📁 file
🔢 number
🚀 submit
```

# 🧱 SEMANTIC HTML

Semantic tags give meaning to your webpage structure.

```html
<header>
    Header
</header>

<nav>
    Navigation
</nav>

<main>

    <section>

        <article>
            Article Content
        </article>

    </section>

</main>

<aside>
    Sidebar
</aside>

<footer>
    Footer
</footer>
```

### 🌟 Important Semantic Tags

| Tag         | Meaning         |
| ----------- | --------------- |
| `<header>`  | 🟣 Header       |
| `<nav>`     | 🔵 Navigation   |
| `<main>`    | 🟢 Main content |
| `<section>` | 🟡 Section      |
| `<article>` | 🟠 Article      |
| `<aside>`   | 🔴 Side content |
| `<footer>`  | 🟤 Footer       |
